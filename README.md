## COMPONENTS AND CONNECTIONS
Thank you.
Now, I will explain the components used in our project.

**1. Arduino Uno:**

Arduino Uno is the main controller of our project. It receives input from the push button and controls the LED and LCD display.

**2. Push Button:**

The push button is used as an input device. Whenever we press the button, it sends a signal to the Arduino.

**3. LED:**

LED stands for Light Emitting Diode. It is used as the output device to indicate whether the light is ON or OFF.

**4. LCD Display:**

We use a 16×2 LCD display. It displays messages such as "LED ON" and "LED OFF".

**5. Resistor:**

A resistor is used to limit the current flowing through the LED and protect it.

**6. Potentiometer:**

The potentiometer is used to adjust the contrast of the LCD display so that the characters are clearly visible.

**Connections:**

The push button is connected to digital pin 2 of Arduino.

The LED is connected to digital pin 8 through a resistor.

The LCD is connected to Arduino using digital pins 12, 11, 5, 4, 3 and 7.

The potentiometer is connected to the contrast pin of the LCD.

**Working principle:**

First, when we start the simulation, the LED remains in the OFF condition.

The LCD displays "LED OFF".

When we press the push button for the first time, the Arduino detects the input signal and changes the LED state from OFF to ON.

At the same time, the LED glows and the LCD displays "LED ON".

When we press the push button again, the Arduino changes the LED state from ON to OFF.

Now, the LED stops glowing and the LCD displays "LED OFF".

This process continues every time we press the push button.
